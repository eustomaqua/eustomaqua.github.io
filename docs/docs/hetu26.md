我却总在每个深夜编造启程理由

这旅途 没地图 没路标 没人挥手
隐痛来自已愈合的陈年伤口
来自无意拆穿粉饰过的那些荒谬
耳中静默时候 听见心底深埋很久的河流
召唤着 向远方 向尽头 不问以后
那被称作无意义的行走
却是灵魂挣脱绳索的出口
